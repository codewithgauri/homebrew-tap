# Codeymon Homebrew tap

```
brew install --cask codewithgauri/tap/sidekik
```

| Cask | What it is |
|---|---|
| `sidekik` | [Sidekik](https://codeymon.com/download/sidekik/): use an Android tablet as a second screen for your Mac, over USB or Wi-Fi, with touch. |

Update with `brew upgrade --cask sidekik`, remove with `brew uninstall --cask sidekik` (add `--zap` to remove settings too).
